# BudgetPulse

Вебзастосунок для особистого обліку доходів, витрат і місячного бюджету. Створений для студентів і користувачів, яким потрібен простий та прозорий контроль фінансів без складних таблиць.

## Можливості

- Додавання, редагування та видалення операцій (витрати та доходи) за категоріями.
- Встановлення ліміту бюджету та відстеження поточного залишку.
- Фільтрація записів за категоріями та періодом.
- Перегляд підсумкової статистики витрат.

## Встановлення / запуск

1. Клонуйте репозиторій та перейдіть у теку проєкту:

`git clone https://github.com/tarasshyn-design/budget-pulse-app.git && cd budget-pulse-app`

2. Встановіть залежності:

`npm install`

3. Створіть файл змінних середовища `.env` на основі `.env.example` і заповніть параметри (`PORT=3000`, `DATABASE_URL=...`):

`cp .env.example .env`

4. Запустіть проєкт у режимі розробки:

`npm run dev`

Після запуску додаток зазвичай відкривається за адресою `http://localhost:3000`.

## Приклад використання

Приклад створення запису витрати через API (або аналогічну форму в інтерфейсі):

`curl -X POST http://localhost:3000/api/transactions -H "Content-Type: application/json" -d '{"type":"expense","amount":150,"category":"Харчування","date":"2026-11-27"}'`

Після збереження операції система оновлює загальну суму витрат і доступний залишок бюджету.
